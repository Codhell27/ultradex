# UltraDex Gothic OS (Offline Edition)

A 100% offline-ready personal productivity OS styled in dark Gothic aesthetic, featuring Chronicles, Grimoire daily journals, numerology trackers, and procedural web audio.

## Building the APK via GitHub Actions (No Android Studio Required)

1. Create a new repository on GitHub.
2. Extract and upload all files from this ZIP to your GitHub repository main branch.
3. Go to the **Actions** tab in your repository.
4. Click on **Build Android APK** workflow and watch it compile.
5. Once finished, download `app-debug.zip` from the **Artifacts** section, unzip it, and install `app-debug.apk` on your Android device!
